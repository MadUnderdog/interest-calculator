# 🏦 คำนวณดอกเบี้ย รถยนต์ & บ้าน

เครื่องมือคำนวณสินเชื่อรถยนต์และบ้าน พร้อมเปรียบเทียบหลายคัน

🔗 **เว็บ:** https://madunderdog.github.io/interest-calculator/
📦 **Repo:** https://github.com/MadUnderdog/interest-calculator

---

## 📋 ฟีเจอร์

### 🚗 คำนวณสินเชื่อรถยนต์
- คำนวณหลายงวดพร้อมกัน (48/60/72/84 เดือน)
- รองรับ **Flat Rate** และ **Effective Rate** (ลดต้นลดดอก)
- **ส่วนลด** — กรอกจำนวนส่วนลด และเลือกหักจากเงินดาวน์หรือจากราคา
- **ของแถม** — เลือกของแถมที่ได้รับ (ประกัน, พรบ., ฟิล์ม, กล้อง, ฯลฯ)
- **Auto-name** — ถ้าไม่กรอกชื่อรถ ระบบจะตั้งชื่อ "รถยนต์ 1, 2, 3..." อัตโนมัติ

### 🏠 คำนวณสินเชื่อบ้าน
- รองรับ **อัตราดอกเบี้ยหลายช่วงเวลา** (เช่น ปีที่ 1 คงที่, ปีที่ 2-5 MRR±)
- รองรับ **MRR** (Minimum Lending Rate) — กรอกค่า MRR แล้วระบบคำนวณ % จริงให้
- **ประเภทลูกค้า** — เลือก สวัสดิการ / รายย่อย / อุปกรณ์ฯ → เติม preset อัตโนมัติ
- เพิ่ม/ลบ/แก้ไขช่วงดอกเบี้ยได้ตามต้องการ
- ตารางผ่อนชำระแบบ reducing balance ทุกงวด

### 📊 เปรียบเทียบ
- เปรียบเทียบรถยนต์หลายคัน side-by-side
- แบ่งกลุ่มข้อมูล: ข้อมูลรถ, ค่างวดแต่ละงวด, สรุปคะแนน
- ระบบ **คะแนนรวม** แนะนำคันที่คุ้มค่าที่สุด
- **🖨️ พิมพ์** — กดปุ่มพิมพ์ได้เลย

### 💡 亮点
- **Two-way sync** — เปลี่ยน % → ค่างวดปรับตาม / กรอกค่างวด → เงินดาวน์ปรับตาม
- **Real-time preview** — ค่างวดคำนวณทันทีขณะพิมพ์
- **ประวัติ** — เก็บผลคำนวณล่าสุด 20 รายการ
- **📄 ใบเสนอราคา** — สร้างใบเสนอราคาสินเชื่อรถยนต์ + พิมพ์ได้

## 🚀 วิธีใช้งาน

### หน้ารถยนต์
1. กรอกราคารถ (บาท)
2. กรอกส่วนลด (ถ้ามี) — กด toggle "หักดาวน์" ถ้าต้องการหักจากเงินดาวน์
3. ตั้งเงินดาวน์ (% หรือ จำนวนเงิน)
4. กรอกดอกเบี้ย % ต่อปี สำหรับแต่ละงวด (กรอกเฉพาะงวดที่ต้องการ)
5. เลือกวิธีคิด: Flat Rate หรือ Effective Rate
6. กด **คำนวณ**

> 💡 **Two-way sync:** พิมพ์ค่างวดที่ต้องการในช่องล่าง → ระบบจะคำนวณเงินดาวน์ที่ต้องปรับให้อัตโนมัติ

### หน้าบ้าน
1. กรอกราคาบ้าน / วงเงินกู้
2. ตั้งเงินดาวน์ (% หรือ จำนวนเงิน)
3. ตั้งระยะเวลา (ปี)
4. กรอก **MRR ปัจจุบัน** (% ต่อปี)
5. เลือก **ประเภทลูกค้า** → ระบบเติม preset อัตโนมัติ
6. แก้ไข/เพิ่ม/ลบช่วงดอกเบี้ยได้ตามต้องการ
7. กด **คำนวณ**

### หน้าเปรียบเทียบ
1. คำนวณรถยนต์อย่างน้อย 2 คันก่อน
2. กดแท็บ "📊 เปรียบเทียบ"
3. เลือกรถยนต์ที่ต้องการเปรียบเทียบ
4. กด **เปรียบเทียบ**
5. ผลลัพธ์แบ่งเป็น 3 ส่วน: ข้อมูลรถ → ค่างวดแต่ละงวด → สรุปคะแนน
